# CodSoft Internship - Task 3: Data Visualization

## 📌 Project Overview
This project focuses on exploring and visualizing retail sales data using Python. Various charts and graphs are created to identify sales patterns, understand product category performance, and explore relationships between customer age and transaction amounts.

## 🎯 Objectives
- Visualize sales data using different types of charts.
- Analyze sales performance across product categories.
- Understand the distribution of transaction amounts.
- Explore monthly sales trends.
- Identify useful insights from the dataset.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset
**Dataset:** Retail Sales Dataset

The dataset includes the following columns:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## 📊 Visualizations Created
1. **Bar Chart:** Total sales by product category.
2. **Line Chart:** Monthly sales trend.
3. **Pie Chart:** Product category distribution.
4. **Histogram:** Distribution of total sales amounts.
5. **Scatter Plot:** Relationship between customer age and total transaction amount.

## 🔍 Analysis and Insights
The project calculates and examines:
- Total sales amount.
- Number of transactions.
- Average transaction amount.
- Product category generating the highest revenue.
- Most frequent product category.
- Month with the highest sales.

These visualizations help summarize retail sales patterns and support data-driven observations.

## ▶️ How to Run the Project
1. Download or clone this repository.
2. Open the `.ipynb` notebook in Google Colab or Jupyter Notebook.
3. Upload the retail sales dataset when required.
4. Run the notebook cells in order to generate the visualizations and insights.

## ✅ Conclusion
This project demonstrates how Python visualization libraries can be used to explore retail sales data and communicate findings through charts and graphs. It provides practical experience in data analysis, visualization, and interpreting business data.
